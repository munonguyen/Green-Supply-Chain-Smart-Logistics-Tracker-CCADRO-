🏛️ 1. Quy Chuẩn Spring Modulith & Ranh Giới Module

Dự án CCADRO được xây dựng theo mô hình Modular Monolith. Các module (Asset, Shipment, Routing, Tracking, Carbon, Exception) được kiểm soát ranh giới nghiêm ngặt bằng Spring Modulith:

⚠️ QUY TẮC CỐT TỬ: Trong cùng module được dùng @ManyToOne. Nhưng giữa 2 module khác nhau, TUYỆT ĐỐI KHÔNG khai báo entity quan hệ trực tiếp. Hãy chỉ lưu UUID để tránh phụ thuộc vòng và fail test kiến trúc. 
// ❌ SAI - Phá vỡ ranh giới Module Tracking -> Asset:
@ManyToOne
private Vehicle vehicle;

// ✅ ĐÚNG - Giữ tính độc lập Modulith:
@Column(name = "vehicle_id", nullable = false)
private UUID vehicleId;
☕ 2. Chuẩn Thiết Kế Entity Với Lombok

Để code sạch sẽ và chuyên nghiệp nhất, áp dụng bộ Annotation chuẩn sau cho mọi Entity JPA: 

package com.ccadro.asset.domain;

import jakarta.persistence.*;
import lombok.*;
import lombok.experimental.FieldDefaults;
import java.math.BigDecimal;
import java.time.Instant;
import java.util.UUID;

@Entity
@Table(name = "vehicle")
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@FieldDefaults(level = AccessLevel.PRIVATE)
public class Vehicle {

    @Id
    @GeneratedValue(strategy = GenerationType.AUTO)
    UUID id;

    @Column(name = "vehicle_code", nullable = false, unique = true, length = 50)
    String vehicleCode;

    @Column(name = "max_payload_tons", nullable = false, precision = 10, scale = 2)
    BigDecimal maxPayloadTons;

    @Column(name = "created_at", nullable = false, updatable = false)
    Instant createdAt = Instant.now();
}
💡 Mẹo IntelliJ: Chú ý khi gõ AccessLevel.PRIVATE, luôn chọn lombok.AccessLevel thay vì class CloudFoundry của Spring Actuator nhé!
📍 3. Xử Lý Hình Học Không Gian PostGIS (JTS Spatial)

Hệ thống dùng Hibernate Spatial kết nối PostGIS. Điểm tọa độ và tuyến đường polyline được định nghĩa như sau: 

import org.locationtech.jts.geom.Point;
import org.locationtech.jts.geom.LineString;
import com.fasterxml.jackson.annotation.JsonIgnore;

// 1. Tọa độ điểm xuất phát / đích đến (WGS 84 SRID 4326):
@JsonIgnore
@Column(name = "origin_geom", nullable = false, columnDefinition = "geometry(Point, 4326)")
Point originGeom;

// Getter tiện ích trả về kinh độ / vĩ độ cho REST API JSON:
public Double getOriginLatitude() { return originGeom != null ? originGeom.getY() : null; }
public Double getOriginLongitude() { return originGeom != null ? originGeom.getX() : null; }

// 2. Polyline hình học tuyến đường:
@JsonIgnore
@Column(name = "route_geometry", columnDefinition = "geometry(LineString, 4326)")
LineString routeGeometry;

⚡ Bộ Lệnh Điều Khiển Hệ Thống (Make Tooling)

Hệ thống đã được đóng gói toàn diện bằng Makefile giúp bạn khởi động và kiểm thử chỉ bằng 1 dòng lệnh:

# 1. Khởi tạo toàn bộ môi trường (Docker PostgreSQL 5433, Redis 6379, Flyway migration):
make setup

# 2. Khởi động đồng thời Containers, Backend Spring Boot (8080) và Frontend Vite (5173):
make start

# 3. Chạy kiểm thử song song Backend (JUnit/Modulith) và Frontend (Vitest):
make test

# 4. Chạy bộ 8 bài kiểm tra smoke test đầu cuối (E2E Validation):
make smoke

# 5. Các kịch bản mô phỏng GPS xe di chuyển:
make simulate-normal       # Xe di chuyển chuẩn theo tuyến
make simulate-deviation    # Xe lệch tuyến 300m (kích hoạt cảnh báo Đỏ UC09 và đề xuất đổi tuyến UC10)
make simulate-traffic      # Xe gặp điểm nghẽn tắc đường trên lộ trình

# 6. Dọn dẹp tiến trình dev server:
make stop
