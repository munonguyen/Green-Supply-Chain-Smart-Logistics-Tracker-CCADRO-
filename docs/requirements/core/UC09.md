# UC09: Real-Time GPS Tracking & Route Deviation Monitoring

## 1. Objective
Ingest high-frequency vehicle GPS telemetry, match positions against the active route geometry, and alert dispatchers when the vehicle deviates beyond authorized corridors.

## 2. Requirements & Triggers
- **ID**: `CORE-TR-009`
- **Trigger**: Telemetry ingested via `POST /api/v1/tracking/telemetry`.
- **Spatial Function**: PostGIS `ST_Distance` or `ST_ClosestPoint` between GPS point and planned `route_geometry`.

## 3. Thresholds & Alert Levels
- **Yellow Warning**: Deviation distance $> 50\text{m}$ for $\ge 3$ consecutive GPS points.
- **Red Alert**: Deviation distance $> 200\text{m}$ for $\ge 3$ consecutive GPS points.

## 4. Verification Acceptance
- Ingested points stored in `telemetry_event`.
- Crossing threshold automatically creates a `deviation_alert` with severity (`YELLOW` or `RED`).
- UI displays pulse warning marker at off-route coordinates.
