# UC12: Post-Trip Carbon Accounting (GLEC Framework v3)

## 1. Objective
Calculate authoritative, audit-ready greenhouse gas emissions (Well-to-Wheel kgCO₂e) for completed or in-progress trips in compliance with GLEC Framework v3 and ISO 14083.

## 2. Requirements & Triggers
- **ID**: `CORE-CA-012`
- **Trigger**: Trip completion or periodic operational audit.

## 3. Mathematical Formula
$$\text{Emission} = (\text{Cargo Payload Tons} \times \text{Distance km}) \times F_{tonne\text{-}km}$$
Where:
- $F_{tonne\text{-}km}$ is retrieved from `emission_factor` table based on fuel type (e.g. Diesel Euro 5 default = $0.080000\text{ kgCO}_2\text{e/t-km}$).
- Empty running legs are calculated with empty vehicle factor $F_{empty}$.
- Rule: Actual GPS distance must NOT be multiplied by Distance Adjustment Factor (DAF) twice.

## 4. Verification Acceptance
- Audit result saved in `emission_calculation` with method `GLEC_V3`.
- Stored details include calculation type, payload, distance, and final kgCO₂e.
