# UC05: Multi-Criteria Route Optimization Specification

## 1. Objective
Generate, evaluate, and rank candidate routes between freight origin and destination by balancing carbon emissions (kgCO₂e), transport duration, and transit distance.

## 2. Requirements & Triggers
- **ID**: `CORE-RO-005`
- **Trigger**: Dispatcher or API initiates route calculation for a `PLANNED` shipment.
- **Provider Interface**: `RoutingProvider` (Mock, OSRM, GraphHopper).

## 3. Algorithm & Scoring Criteria
The composite score $S$ is calculated as a normalized multi-criteria objective:
$$S = w_{co2} \cdot \hat{C} + w_{time} \cdot \hat{T} + w_{dist} \cdot \hat{D}$$
Where:
- $w_{co2} = 0.50$ (Priority on carbon footprint minimization)
- $w_{time} = 0.30$ (Delivery punctuality constraint)
- $w_{dist} = 0.20$ (Wear-and-tear & toll optimization)

## 4. Verification Acceptance
- Must return at least 3 distinct ranked candidates.
- Must include complete LineString geometry and waypoints in GeoJSON format.
- Recommended route is flagged and persisted in `route_candidate`.
