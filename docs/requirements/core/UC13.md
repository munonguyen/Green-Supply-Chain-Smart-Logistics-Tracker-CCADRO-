# UC13: Freight Corridor Carbon Benchmarking

## 1. Objective
Aggregate and benchmark fleet emission intensity (kgCO₂e/tonne-km) across specific geographical logistics corridors against market averages and green leader baselines.

## 2. Requirements & Triggers
- **ID**: `CORE-BM-013`
- **Trigger**: Monthly analytics generation or dispatcher dashboard view.

## 3. Analytics Scope
- **Corridor**: HCMC Port Cluster $\leftrightarrow$ Binh Duong VSIP Industrial Hub.
- **Metrics**:
  - `average_co2e_per_tonne_km`: Market average across peer logistics operators ($0.0820$).
  - `best_in_class_co2e_per_tonne_km`: Top-decile green fleet performance ($0.0680$).
  - `relative_saving_percentage`: Fleet performance variance against baseline.

## 4. Verification Acceptance
- Corridors queried via `GET /api/v1/carbon/benchmarks`.
- Visualized in UI comparison cards with savings percentages.
