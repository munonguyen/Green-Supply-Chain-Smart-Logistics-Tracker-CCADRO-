BRULE-01 Safety Eligibility Gate Phương tiện đang bảo dưỡng (MAINTENANCE) hoặc biên bản kiểm định pre_trip_inspection có trạng thái FAILED tuyệt đối không được phép điều vận hoặc khởi hành chuyến đi. Hệ thống từ chối tạo lệnh dispatch_order và chặn không cho tài xế bấm nút "Bắt đầu chuyến". Ném ngoại lệ BusinessRuleViolationException.
BRULE-02 Master Uniqueness Mã xe (vehicle_code), Biển số (plate_number), Mã tài xế (driver_code) và Mã container (container_code) phải là duy nhất trên toàn hệ thống. PostgreSQL kích hoạt ràng buộc UNIQUE constraint; Service bắt lỗi và trả về HTTP 409 Conflict với thông điệp rõ ràng cho người dùng.
Checklist Audit Pre-Trip 6 Điểm An Toàn Tài xế phải xác nhận 6 hạng mục an toàn trong checklist_json: 1. Lốp xe (tires), 2. Phanh (brakes), 3. Đèn (lights), 4. Dầu phanh/nước làm mát (fluids), 5. Bình cứu hỏa (fire_extinguisher), 6. Khóa chốt container (cargo_securing). Nếu có bất kỳ mục nào = FAIL $\rightarrow$ critical_failures_count > 0 $\rightarrow$ Biên bản tự động đánh dấu FAILED.

Luồng xử lý khi tài xế đăng nhập vào ứng dụng và điền biên bản an toàn tại bãi xe trước khi xuất phát:

2. Điền Checklist 6 điểm an toàn trên App
➔
3. Gửi POST /api/v1/assets/inspections
➔
4. Backend kiểm tra: Có hạng mục nào FAIL không?
NẾU CÓ ✘:
• status = FAILED
• vehicle.status = MAINTENANCE
• Báo động Dispatcher: Xe hỏng, cấm khởi hành!
NẾU ĐẠT ✔:
• status = PASSED
• vehicle.status = AVAILABLE (Sẵn sàng nhận chuyến)
• Cho phép bước tiếp theo: Điều phối & Lập tuyến!

Chốt 2: Có lịch bảo dưỡng nào đang ở trạng thái IN_PROGRESS không? (Nếu có $\rightarrow$ Chặn)
Chốt 3: Biên bản kiểm tra an toàn PreTripInspection gần nhất có phải PASSED không? (Nếu FAILED $\rightarrow$ Chặn)

1. Container.java (Tạo tại: com.ccadro.asset.domain)

package com.ccadro.asset.domain;

import jakarta.persistence.*;
import lombok.*;
import lombok.experimental.FieldDefaults;
import java.math.BigDecimal;
import java.time.Instant;
import java.util.UUID;

@Entity
@Table(name = "container")
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@FieldDefaults(level = AccessLevel.PRIVATE)
public class Container {

    @Id
    @GeneratedValue(strategy = GenerationType.AUTO)
    UUID id;

    @Column(name = "container_code", nullable = false, unique = true, length = 50)
    String containerCode;

    @Column(name = "container_type", nullable = false, length = 30)
    String containerType; // DRY_20FT, DRY_40FT, REEFER_20FT, REEFER_40FT...

    @Column(name = "tare_weight_tons", nullable = false, precision = 10, scale = 2)
    BigDecimal tareWeightTons;

    @Column(name = "max_payload_tons", nullable = false, precision = 10, scale = 2)
    BigDecimal maxPayloadTons;

    @Column(name = "is_reefer", nullable = false)
    Boolean isReefer = false;

    @Column(name = "status", nullable = false, length = 30)
    String status = "AVAILABLE";

    @Column(name = "created_at", nullable = false, updatable = false)
    Instant createdAt = Instant.now();
}

2. PreTripInspection.java (Tạo tại: com.ccadro.asset.domain)

package com.ccadro.asset.domain;

import jakarta.persistence.*;
import lombok.*;
import lombok.experimental.FieldDefaults;
import java.time.Instant;
import java.util.UUID;

@Entity
@Table(name = "pre_trip_inspection")
@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@FieldDefaults(level = AccessLevel.PRIVATE)
public class PreTripInspection {

    @Id
    @GeneratedValue(strategy = GenerationType.AUTO)
    UUID id;

    @Column(name = "vehicle_id", nullable = false)
    UUID vehicleId;

    @Column(name = "driver_id", nullable = false)
    UUID driverId;

    @Column(name = "shipment_id")
    UUID shipmentId;

    @Column(name = "status", nullable = false, length = 20)
    String status = "PASSED"; // PASSED, FAILED

    @Column(name = "checklist_json", columnDefinition = "jsonb")
    String checklistJson;

    @Column(name = "critical_failures_count", nullable = false)
    Integer criticalFailuresCount = 0;

    @Column(name = "remarks", columnDefinition = "text")
    String remarks;

    @Column(name = "inspection_time", nullable = false)
    Instant inspectionTime = Instant.now();
}
